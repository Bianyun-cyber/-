# db · 数据库

依据：锁定版数据库结构（2026-09-25），共 **7 张表**。

| 文件 | 内容 |
|---|---|
| `schema.sql` | 建库语句（7 张表 + 索引 + `pg_trgm`），照锁定版一字不改 |

## 7 张表

1. `dream_topics` —— 父主题
2. `dream_scenes` —— 具体梦境页面（最核心，含 8 个搜索字段 + content）
3. `dream_scene_aliases` —— 搜索别名（只人工确认后加）
4. `search_terms` —— 搜索词归一库
5. `dream_nearby` —— 相关梦境关系
6. `search_logs` —— 搜索日志
7. `dream_submissions` —— 用户提交的梦境

## 核心原则

- 页面是提前写好的成品，数据库只帮用户找到页面
- 结构化字段只用于搜索匹配/排序，不是知识库
- 正常搜索不调 AI
- 归一化不丢颜色/动作/地点/状态
- Alias 禁止自动写入
